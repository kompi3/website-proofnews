## Development

When starting the dev server, use background mode:

```
astro dev --background
```

Manage the background server with `astro dev stop`, `astro dev status`, and `astro dev logs`.

## Lessons
- BaseHead.astro MUST keep `import '../styles/global.css'` and the @fontsource imports at the top. A rewrite once dropped them and the entire site lost its global styling (only scoped component CSS remained). After any BaseHead change, rebuild and verify the global selectors (e.g. `.stars`, `.btn`, `body{`) exist in dist output.
